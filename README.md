# Debt Consolidation — Mesa Group Consulting

Standalone prototype for the **Debt Consolidation Loan** landing page, powered by SuperMoney.

Helps consumers combine multiple high-interest debts into a single lower-rate loan, simplifying payments and reducing total interest cost.

## Tech Stack
React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui
